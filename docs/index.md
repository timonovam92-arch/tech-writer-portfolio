## О проекте

Данная документация создана в процессе работы администратором баз знаний. Проект демонстрирует навыки:

- Сбора и структурирования информации от нескольких экспертов (комплаенс-отдел, юристы, разработчики)
- Описания алгоритмов проверки и интерпретации результатов
- Написания инструкций для пользователей
- Визуализации уровней риска для быстрого принятия решений
