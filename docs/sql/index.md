# SQL: базовый уровень

В рамках самообучения я прошла курс по SQL и научилась писать запросы для анализа данных. Этот навык помогает мне лучше понимать, как устроены базы данных, и позволяет проверять информацию при работе с документацией.

## Зачем мне SQL

Как технический писатель, я работаю с большими объёмами информации: описания API, базы знаний, инструкции. Понимание SQL даёт мне три преимущества:

1. **Я могу проверять данные** — если в документации указано число или статус, я могу убедиться, что они верны.
2. **Я говорю с аналитиками и разработчиками на одном языке** — мне не нужно объяснять, что я имею в виду, когда говорю о таблицах, связях или выборках.
3. **Я умею анализировать обратную связь** — могу выгружать данные из систем и делать выводы.

## Что я умею

- **Выборка и фильтрация:** `SELECT`, `FROM`, `WHERE`, `AND`, `OR`, `IN`, `BETWEEN`.
- **Агрегация:** `COUNT`, `SUM`, `AVG`.
- **Группировка:** `GROUP BY`.
- **Работа с датами:** `EXTRACT`, `DATE_TRUNC`, `CURRENT_DATE`, `INTERVAL`.
- **Сортировка:** `ORDER BY`.
