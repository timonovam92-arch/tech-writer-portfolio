## О портфолио

В этом портфолио представлены примеры моей работы в области технической документации: пользовательские гайды, документация к API, базы знаний, стайлгайд и работа с данными через SQL.

Цель портфолио — показать мой подход к структурированию информации, написанию текстов для разных аудиторий и работе с современными инструментами.

## Что вы найдете здесь

- **AML-гайд** — пользовательская документация для сотрудников отдела модерации.
- **Сервис уведомлений** — документация к API с примерами запросов и ответов.
- **База знаний для поддержки** — схема процесса обработки инцидентов.
- **Стайлгайд** — правила оформления и стандарты документации.
- **SQL** — примеры запросов для анализа данных.

## Обо мне

Я — специалист по технической документации и управлению знаниями. Создаю документацию, которая решает задачи пользователей и снижает нагрузку на поддержку. Владею инструментами Docs as Code (MkDocs, Markdown, Git), умею визуализировать сложные процессы и адаптировать тексты под разные уровни подготовки пользователей.

Развиваюсь в сторону технического писателя и Knowledge Manager в IT-компаниях.
