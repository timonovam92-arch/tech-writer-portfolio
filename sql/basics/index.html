    Основы SQL

    Что такое SQL

    SQL (Structured Query Language) — это язык для работы с базами данных. С его помощью можно выбирать, фильтровать, группировать и анализировать данные.

    Основные команды

    SELECT и FROM

    SELECT column_name
FROM table_name
    • SELECT — какие столбцы вывести.
    • FROM — из какой таблицы.

    WHERE — фильтрация строк

    SELECT *
FROM tickets
WHERE status = 'closed'
    • WHERE фильтрует строки до группировки.
    • Работает со скалярными функциями (EXTRACT, DATE_TRUNC), но не с агрегатными (COUNT, SUM, AVG).

    GROUP BY — группировка

    SELECT status, COUNT(*)
FROM tickets
GROUP BY status
    • Группирует строки по значению столбца.
    • Используется вместе с агрегатными функциями.

    HAVING — фильтрация групп

    SELECT status, COUNT(*) AS total
FROM tickets
GROUP BY status
HAVING COUNT(*) > 10
    • HAVING фильтрует уже сгруппированные данные.
    • В отличие от WHERE, работает с агрегатными функциями (COUNT, SUM, AVG).
    • Используется после GROUP BY.

    Правило: - WHERE — фильтрует строки до группировки. - HAVING — фильтрует группы после группировки.

    ORDER BY — сортировка

    SELECT *
FROM tickets
ORDER BY created_at DESC
    • ASC — по возрастанию (по умолчанию).
    • DESC — по убыванию.

    LIMIT и OFFSET — ограничение вывода

    SELECT *
FROM tickets
ORDER BY created_at DESC
LIMIT 10 OFFSET 20
    • LIMIT — сколько строк вывести (в данном примере — 10).
    • OFFSET — сколько строк пропустить (в данном примере — 20).
    • Используется для пагинации — постраничного вывода данных.

    Пример пагинации: - Страница 1: LIMIT 10 OFFSET 0 - Страница 2: LIMIT 10 OFFSET 10 - Страница 3: LIMIT 10 OFFSET 20

    Агрегатные функции

    Функция Что делает
    COUNT Считает количество строк
    SUM Суммирует значения
    AVG Считает среднее
    MIN / MAX Находит минимум / максимум

    Работа с датами

    Функция Что делает
    EXTRACT Вытаскивает часть даты (год, месяц, день)
    DATE_TRUNC Обрезает дату до нужного уровня
    CURRENT_DATE Возвращает сегодняшнюю дату
    INTERVAL Создаёт отрезок времени

    Пример: заявки за последние 7 дней

    SELECT COUNT(*)
FROM tickets
WHERE created_at >= CURRENT_DATE - INTERVAL '7 days'

    Порядок блоков в SQL

    Важно запомнить порядок:

    SELECT ...
FROM ...
WHERE ...
GROUP BY ...
HAVING ...
ORDER BY ...
LIMIT ...
OFFSET ...

    Порядок выполнения: 1. FROM — берём таблицу. 2. WHERE — фильтруем строки. 3. GROUP BY — группируем. 4. HAVING — фильтруем группы. 5. SELECT — выбираем столбцы. 6. ORDER BY — сортируем. 7. LIMIT / OFFSET — ограничиваем вывод.

    Что важно запомнить

    1. Порядок блоков критичен. FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT.
    2. WHERE работает со скалярными функциями, а HAVING — с агрегатными.
    3. LIMIT и OFFSET — для пагинации. LIMIT — сколько строк, OFFSET — сколько пропустить.
    4. Даты — это отдельная тема. EXTRACT, DATE_TRUNC, CURRENT_DATE, INTERVAL решают большинство задач.
    5. ROUND помогает сделать результат читаемым.
