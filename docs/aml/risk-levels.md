## Принимаем решение на основе результатов

<span class="text-green">Зеленый результат проверки</span> - пользователь не найден в запрещённых базах, <span class="text-green">одобряем</span>.<br>
<span class="text-red">Красный результат проверки</span> - пользователь найден в запрещённых базах, <span class="text-red">отказываем</span> в соответствии с политикой AML.
 
Проверяем совпадения, оцениваем риск-скоринг. Если есть сомнения наш ли пользователь, открываем отчёт через "Скачать результат AML":

- пользователь наш и найден в запрещённых базах - анкета <span class="text-red">блокируется</span> соответствующей кнопкой
- ложно-положительное совпадение/пользователь не найден в запрещённых базах - самостоятельно меняем на <span class="text-green">зеленый</span>, нажав на иконку карандаша рядом с результатом проверки, и <span class="text-green">одобряем</span> анкету.

!!! note ""
**Риск-скоринг** - автоматизированная оценка по совпадению с вышеперечисленными категориями на связь с незаконной деятельностью. В проверке выводится в скобках у найденных результатов. 
!!! note ""

Решение принимается на основе риск-скоринга и подтверждения данных. 

Если риск-скоринг:

- <span class="text-underline">от 60 и выше</span>: совпадение считается **подтверждённым** — отказываем соответствующей кнопкой. 
- <span class="text-underline">50-60</span>: ручная проверка — **изучаем отчёт** ("Скачать результат AML"), после чего принимаем решение.
- <span class="text-underline">ниже 50</span>: проверка пройдена — **одобряем**, если в анкете нет других нарушений (в первое время рекомендуется дополнительно изучать отчёт, чтобы убедиться в отсутствии ошибок системы).


Отчёт - это файл, который содержит все данные по пользователю из открытых источников. Откройте его в Блокноте или браузере. В браузере нажмите «Автоформатировать», чтобы данные отображались аккуратнее.
 
В самом отчёте находим информацию (через **crtl + F**), которая относится именно к нашему пользователю, и связанных с ним нарушений. 

Для быстрого поиска можно пользоваться ключевыми словами. **Например**: 

- ФИО и ДР проверяемого пользователя в разных формах
- PEP / Politically exposed person
- SIP / Special Interest Person
- Sanction / Sanction list
- и др.
